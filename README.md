# Game Collection project

## Description
After changing and thinking what my project for bootdev's course 12 project could be, I have decided that I will build a collection of games

**Games**
- BlackJack
- TicTacToe
- Rock_Paper_Scissors

It is not the first time that I have build this games from scratch. Nonetheless, it is the first time that I will revisit this games after going through all the bootdevs courses.

## Main objective
The main objective of this project is to put in effort my abilities as a developer, to be able to prove my proficiency with git, and the implementation of different files into one project.

Each Game will game will have its own README where a description of the game plus the rules can be found. If it's possible I will look for one more game that can be added into this collection. Nonetheless, for now. I will include only three games into this simple collection. 

It is also important to remark that this games will only be able to work in the computers terminal, but I will try to display them with some ASCII art.

# TicTacToe Game

## Game Description
two players are working, whoever was three icons in line wins, there are 9 spaces

## RULES
1. Any player who was three symbols in line wins
2. You can not place on the same spot as someone already placed something before
3. You win if you have three of the same symbols vertical "|"
4. You win if you have three of the same symbols horizontal "-"
5. You win if you have three of the same symbls diagonal "/" or "\
